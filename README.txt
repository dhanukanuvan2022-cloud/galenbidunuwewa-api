GALENBINDUNUWEWA API - Website files

Files:
- index.html: website content
- styles.css: colours, layout and responsive design
- script.js: mobile menu and current year
- assets/design-reference.png: visual concept reference (if included)

How to preview on Kali Linux:
1. Extract the ZIP file.
2. Open the extracted folder in File Manager.
3. Double-click index.html to open it in Firefox.

For a local web server (optional):
Open Terminal in this folder and run:
  python3 -m http.server 8000
Then visit:
  http://127.0.0.1:8000
